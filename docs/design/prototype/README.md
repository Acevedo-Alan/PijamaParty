# Store prototype (reference only)

`index.html` is the visual prototype of the store. It is a **read-only reference**: it is not production code, it is
not built and it is not deployed. Its inline scripts and its Google Fonts link are not used by the real frontend.

The design tokens taken from it, with the accessibility corrections, are in `ARCHITECTURE.md` section 11 and in
`frontend/src/styles/tokens.css`.
